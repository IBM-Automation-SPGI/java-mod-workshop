Sobre el workshop

Este workshop práctico te guiará por el proceso completo de modernizar una aplicación Java empresarial real — PedjasApp, un sistema de gestión de pedidos con EJBs, Servlets, JMS y JDBC — desde WebSphere Application Server tradicional hasta WebSphere Liberty e incluso despliegue cloud-native en OpenShift. Trabajarás con IBM AMA para obtener reglas de modernización concretas y accionables, y tendrás la opción de utilizar IBM Bob para modernización asistida con IA.

Módulos del laboratorio

Lab 0
Requisitos Previos
Configurar entorno, revisar arquitectura AS-IS / TO-BE y compilar PedjasApp
Lab 1
Despliegue en tWAS
Desplegar y verificar PedjasApp en WebSphere Application Server tradicional
Lab 2
Análisis con AMA
Ejecutar IBM AMA y comprender las reglas de modernización generadas
Lab 3
Modernización Manual
Aplicar cambios de código guiados por AMA (y opción con IBM Bob)
Lab 4
Despliegue en Liberty
Construir el Dockerfile y desplegar en WebSphere Liberty 26.0.0.9
Lab 5
Validación
Verificar la migración funcional y planificar los próximos pasos

Lab 6 (Opcional) — Kubernetes & OpenShift: Despliega la aplicación modernizada en un clúster cloud-native utilizando el Open Liberty Operator. Da el salto definitivo a la nube con configuración GitOps.

Lo que necesitas

  • Java JDK 11 o superior instalado
  • Apache Maven 3.8+
  • Podman 4.x o superior
  • Acceso a IBM Application Modernization Accelerator
  • Cuenta en GitHub
  • Conocimientos básicos de Java EE / Jakarta EE
